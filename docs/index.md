# BoardGameHub API

Welcome to the BoardGameHub API documentation.

## Overview

This API provides access to a board game database, allowing users to browse, search, and manage board game collections.

## Features

- **Authentication**: Secure login with JWT.
- **Board Games**: CRUD operations for board games.
- **Stats**: Real-time statistics and analytics.
- **Pagination & Export**: Efficient data retrieval with pagination and CSV export support.
- **Caching**: ETag support for bandwidth optimization.
